# Internationalization

Resources live in `packages/paint-i18n/locales/<language>/<namespace>.json`.
English is the typed source; supported locales are en, es, fr, de, it, pt-BR, nl,
pl, ru, ja, ko, zh-Hans and zh-Hant. Translate the canonical hobby glossary first,
then use it consistently throughout the seven other namespaces. Keep brands,
product names, commands, URLs, persisted enums and user/plugin content unchanged.

- Use `useTranslation("pages")` / `useTranslation("components")` in React;
  non-React helpers use `@paint-vault/i18n/runtime`. Keys are checked by TypeScript.
- Interpolate variables, never concatenate translated sentences. Format quantities
  as `{{count, number}}`; use the shared date/number/relative-time helpers.
- Complete plural families follow **each language's CLDR categories**, not English
  suffix parity. Keep standalone base keys when the English resource has one.
- The app imports six namespaces for the active language, with no English fallback
  downloads. Site and Electron main separately load `site` and `desktop`; the Vite
  import glob produces local chunks, so no translation service/CDN is needed.
- Site keys are flat dotted strings (`keySeparator: false`); desktop keys are nested.
- Server display errors use stable codes and parameters from `error-catalog.json`.
  Render through `translateServerError`. REST UI catches preserve only explicitly
  localized `PublicError`s; arbitrary transport/JSON/legacy diagnostics are not UI
  copy. Electron restore IPC carries the same codes. Technical crash diagnostics
  and actual user/plugin data remain diagnostic/data, not translation resources.
- Device language is browser-local storage or the serialized native preference,
  independent of the current vault/server. Unsupported OS variants resolve to the
  closest supported language. MUI locale, `Intl`, document language and regional
  CJK sans/serif fallback stacks follow that setting.

## Checks and development

`npm run i18n:check` verifies namespace/key/structure parity, duplicate and empty
values, CLDR plural keys, exact interpolation formats, unused keys and raw JSX
copy. A justified raw-copy exception uses `i18n-allow` (see the repository-format
example in the website docs). Run the ordinary lint/typecheck/test/build/codegen,
format and Storybook gates too. The new runtime tests exercise every plural family
across all 13 languages, including fractional and million-count categories.

Use the Storybook **Locale** toolbar or set browser local storage
`paint-vault-language` to `en-XA` and reload for an accented, approximately 40%
expanded pseudo-locale. It preserves interpolation and markup; it is not offered
in the production language picker.

All smoke tools require the pinned Node in `.nvmrc` and an explicit evidence path.
They use isolated browser storage, temporary vault data and random loopback ports:

```sh
node scripts/smoke-i18n-browser.mjs /absolute/evidence-dir
node scripts/smoke-i18n-site.mjs /absolute/evidence-dir
node scripts/smoke-i18n-stories.mjs /absolute/evidence-dir de 0 10000
node scripts/smoke-i18n-layout-selftest.mjs
node scripts/smoke-i18n-native.mjs /absolute/evidence-dir '/path/Paint Vault.app/Contents/MacOS/Paint Vault'
node scripts/i18n-bundle-report.mjs --baseline /path/to/baseline/dist --output /absolute/evidence-dir/bundle-impact.json
```

The browser tool expects a production app build; the site tool builds only the
site. The native tool expects an existing packaged macOS app and never touches
normal preferences/data. Story sweeps render every indexed initial story state
in the chosen locale; they deliberately skip English play assertions. The full
ordinary Storybook interaction/accessibility gate is separate. Layout checks
measure actual translated text, interpolated plurals, ancestor clipping, document
overflow and actual CJK fonts; they exclude deliberately hidden accessibility text
and intentional truncation of user/plugin titles. Bundle measurement separates the
recursive static startup graph, the six selected-locale chunks, and other lazy
assets; summing every emitted language is **not** startup impact.
